# Tutorial — Figurino Retirada e Devolução

**URL:** `/Ajuda/Tutoriais/FigurinoRetiradaDevolucao`

**Perfil de referência:** Shift Leader, Service Manager ou liderança com **Editar = Sim** em Figurinos  
**Página:** Figurinos  
**Objetivo:** registrar empréstimo temporário (**Emprestada**) e devolução com classificação da peça — manual ou por bipagem.

Imagens em `public/tutoriais/estudio/figurinos/retirada-devolucao/`.

---

## Regras rápidas

| Tipo / ação | Quem usa |
|-------------|----------|
| **Emprestada** | Shift Leader, Service Manager e liderança no turno |
| **Fixo** | Somente equipe de **Figurino** |
| **Editar** | Retirada e Devolução |
| **Criar** | Cadastrar peça, Manutenção, Disponibilizar, Descartar |

## Classificação na devolução

| Opção | Efeito |
|-------|--------|
| **Boa condição** | Volta para **Disponíveis** |
| **Possível descarte** | Volta para **Disponíveis** — **observação obrigatória** |
| **Manutenção** | Vai para aba **Manutenção** (tipo + motivo obrigatórios) |

## Passos (resumo)

1. Figurinos → aba **Disponíveis**
2. **Retirada** manual ou **Bipar código**
3. Prestador + tipo **Emprestada** → **Confirmar Retirada**
4. Conferir aba **Emprestada**
5. **Devolução** manual ou bipagem → classificar condição → **Confirmar devolução**
