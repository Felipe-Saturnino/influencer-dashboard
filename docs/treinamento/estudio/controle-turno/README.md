## Aprovação de Escala de Turno

1. Abrir Escala do Turno (dia + turno)
2. Modal Registrar
3. Sinalizar Falta
4. Saída Antecipada / Hora Adicional / Registrar Horário
5. Aprovar o dia
6. Histórico da linha

## Relatório de Turno

1. Abrir aba Relatório
2. Gerar Relatório (rascunho)
3. Editar Rascunho
4. Publicar (exige Escala aprovada)
5. Consultar dias anteriores + histórico

## Notificação

1. Abrir aba Notificações (4 blocos)
2. Fechamento de Mesa
3. Ausências Prolongadas
4. Feedbacks (atendimento em Solicitações RH)
5. Solicitação de Manutenção
6. Acompanhar status nos dias seguintes
