# Tutorial — Gerar Rotação (Controle de Turno)

**URL:** `/Ajuda/Tutoriais/ControleTurnoRotacao`  
**Página:** Controle de Turno (Estúdio) → aba **Rotação**  
**Público seed:** `shift_leader`, `service_manager`, `gestor_operacoes`  
**Visão:** liderança gerando e publicando a rotação.

Imagens em `public/tutoriais/estudio/controle-turno/rotacao/`.

## Conteúdo

1. Abrir aba Rotação (dia, turno, bloco por estúdio, KPIs, pool)
2. **Gerar prévia** (slots 30 min; ordem aleatória das linhas)
3. **Incluir Liderança** (SL/SM do dia; janela 08h–20h / 20h–08h → X)
4. Protocolo **Rotação de 20min** / **30min** (cobertura / ≤2h contínuas)
5. **Mover estúdio…** / **Restaurar** (override só do dia/turno)
6. Arrastar coluna **Equipe** (troca sequência na mesma grade)
7. **Publicar** (confirmação se ≥2h contínuas em mesa; depois só Regenerar)
