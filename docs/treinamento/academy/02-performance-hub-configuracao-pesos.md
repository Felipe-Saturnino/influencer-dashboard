# Tutorial — Configurar Pesos (Performance Hub)

**URL:** `/Ajuda/Tutoriais/PerformanceHubConfiguracaoPesos`

**Perfil de referência:** Performance Coach com **Criar = Sim**  
**Página:** Performance Hub → Configuração  
**Objetivo:** ajustar pesos de dimensões e critérios do scoring por time.

Imagens em `public/tutoriais/academy/performance-hub-configuracao-pesos/`.

---

## Passos

### 1. Aba Configuração

Menu **Academy** → **Performance Hub** → aba **Configuração** (exige Criar = Sim).

![Configuração](imagens/01-aba-configuracao.png)

### 2. Selecionar time

Filtro **Time** na barra — Game Presenter ou Shuffler (pesos independentes).

![Time](imagens/02-filtro-time.png)

### 3. Peso da dimensão

Comunicação, Imagem, Mesa/Procedimentos — campo **Peso da dimensão** (0–10).

![Dimensão](imagens/03-peso-dimensao.png)

### 4. Peso dos critérios

Tabela por dimensão — coluna **Peso** em cada critério.

![Critérios](imagens/04-peso-criterios.png)

### 5. Salvar

Botão **Salvar** → confirmação **Pesos salvos com sucesso.**

![Salvar](imagens/05-salvar-pesos.png)

---

## Notas

- Alterações valem para **novas** avaliações; publicadas mantêm a nota original.
- Defaults: GP — Comunicação 2, Mesa 2, Imagem 1; Shuffler — Comunicação 1, Imagem 1, Procedimentos 2.
