# Tutorial — Aplicar Feedback (Performance Hub)

**URL:** `/Ajuda/Tutoriais/PerformanceHubAplicarFeedback`

**Perfil de referência:** Shift Leader com **Editar = Sim**  
**Página:** Performance Hub → Feedback  
**Objetivo:** repassar feedback ao prestador que solicitou esclarecimento e encerrar a avaliação (status Aprovado).

Imagens em `public/tutoriais/academy/performance-hub-aplicar-feedback/`.

---

## Passos

### 1. Aba Feedback

Menu **Academy** → **Performance Hub** → filtro **Time** + carrossel → aba **Feedback**.

![Feedback](imagens/01-aba-feedback.png)

### 2. Feedbacks Pendentes

Avaliações em status **Feedback** — coluna **Mensagem** traz a dúvida do prestador.

![Pendentes](imagens/02-feedbacks-pendentes.png)

### 3. Aplicar feedback

Ícone **Aplicar feedback** na coluna Ações (ou **Ver avaliação** só para leitura).

![Ação](imagens/03-acao-aplicar-feedback.png)

### 4. Revisar avaliação

Modal em leitura — abas Dados, Comunicação, Imagem, Mesa/Procedimentos.

![Modal](imagens/04-modal-revisar-avaliacao.png)

### 5. Registrar repasse

Rodapé **Aprovar** → pop-up **Aplicar Feedback** → campo **Feedback** (obrigatório) → **Aprovar**.

![Pop-up](imagens/05-popup-aplicar-feedback.png)

### 6. Feedbacks Aplicados

Linha migra para **Feedbacks Aplicados** com data e aplicador; status **Aprovado**.

![Aplicados](imagens/06-feedbacks-aplicados.png)

---

## Notas

- Prestador solicita feedback na aba **Avaliações** (status Aguardando → Feedback).
- Repasse só pela aba **Feedback** — não pelo ícone na aba Avaliações.
