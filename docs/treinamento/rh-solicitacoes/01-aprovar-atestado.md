# Tutorial — Aprovar Atestado (Solicitações RH)

**URL:** `/Ajuda/Tutoriais/RhSolicitacoesAprovar`  
**Página:** Solicitações (seção RH) → aba **Atestados**  
**Público seed:** `gestor_rh`, `rh`  
**Visão:** membro do time de RH (aprovação). Gestores podem **ver** a lista; só o RH **atende**.

Imagens em `public/tutoriais/rh/solicitacoes/` (`01`–`03`).

## Conteúdo

1. Abrir aba Atestados (Em análise; aviso gestores vs RH)
2. Atender — aba Dados (período e anexo)
3. Aprovar (Status, Abono remunerado SIM/NÃO, observação)
4. **Abono = SIM** — pagamento dos dias escalados no afastamento; Calendário **Abonado**; Escala **Atestado**; Marketplace cancela venda de Folga
5. Abono = NÃO e rejeição (Calendário **Atestado** / volta a **Falta**)
