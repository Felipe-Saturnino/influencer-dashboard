# Tutorial — Registrar e Aprovar Feedback (Solicitações RH)

**URL:** `/Ajuda/Tutoriais/RhSolicitacoesFeedback`  
**Página:** Solicitações (seção RH) → aba **Feedback**  
**Público seed:** `shift_leader`, `service_manager`, `gestor_operacoes`, `gestor_rh`, `rh`  
**Visão:** gestor (registrar e aprovar).

Imagens em `public/tutoriais/rh/solicitacoes/feedback/`.

## Conteúdo

1. Abrir aba Feedback (Em análise; coluna Origem)
2. Registrar Feedback (Time, Prestador, Recomendação, Observação → Registrar)
3. Aprovar feedback da liderança (origem Controle de Turno → Atender → Aprovado = Aplicado no CT)
4. Acompanhar Aplicado / Rejeitado

**Nota:** origem Solicitações não cria linha no Controle de Turno.
