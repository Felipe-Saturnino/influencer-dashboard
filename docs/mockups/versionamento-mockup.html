Acompanhe as novidades, melhorias e correções publicadas a cada semana na plataforma.

Proposta de produto. Página irmã de Ajuda — menu do avatar, abaixo de Ajuda. A primeira release publicada é Release #1; o número sobe a cada semana. O destaque é só a mais recente (tag Recente); o histórico fica recolhido por padrão. Busca: palavras-chave no título da release, resumo, título do bloco, data, tipo, seção e texto dos cards (várias palavras = todas precisam aparecer). Permissão: cada card aponta para a página da feature — quem não tem permissão de Ver (ou Próprios) nessa página não vê o card. Use o seletor Perfil simulado no topo para testar. Feature transversal (ex.: busca nos filtros) aparece para todos que acessam Versionamento.
