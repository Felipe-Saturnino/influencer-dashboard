O que mudou da v1 para a v2

  • Acessibilidade Blocos passam a usar <h2> reais (antes eram <strong>) — leitor de tela navega os 4 blocos por atalho de heading. Skip link para o conteúdo, aria-live no valor do Índice, foco visível (:focus-visible), prefers-reduced-motion respeitado (shimmer do skeleton e blur da barra desligam), e cada variação MoM tem o rótulo (melhora)/(piora) por extenso — não depende só da cor/seta para quem não enxerga cor.
  • Estados Toggle Estado na barra do mockup demonstra os 4 estados reais: Dados, Carregando (skeleton, sem crus 0/vazio), Sem dados («Sem dados para o período selecionado.») e Sem permissão («Você não tem permissão para visualizar este dashboard.»).
  • Layout Nos ecrãs largos os blocos ocupam 2 colunas (Destaque + Comparativo, depois os 4 blocos em pares) — melhor uso do espaço para quem só quer escanear; em telas estreitas volta a 1 coluna.
  • Sugestão nova Bloco Comparativo por Estúdio (toggle, off por padrão) — tabela leve com Blaze e Sports Club lado a lado. O handoff v1 tinha isso como fora de escopo (benchmarking); com só 2 estúdios reais hoje pode valer a pena — reabrir com o PO antes de implementar.
  • Confirmado no código "Estúdio" já existe como entidade real — estudios_spin + estudios_spin_operadoras, estúdios nomeados Blaze e Sports Club (ver estudio.mdc). Isso resolve a pergunta em aberto nº 1 do handoff.
  • Atenção — possível sobreposição dashboards.mdc mostra que Overview Spin já tem abas Estúdio Dedicado e Estúdio Network (visão por canal/receita das mesas). Este painel novo é uma visão diferente — saúde operacional/RH, não canal de receita — mas o nome parecido pode confundir. Vale alinhar com o Tech Lead se "Overview Estúdio" fica em Dashboards como página própria ou se faz mais sentido como aba dentro de Overview Spin.
  • Componentes reais Tech Lead deve trocar os .kpi deste mockup pelo componente KpiCard (src/components/dashboard/KpiCard) — props label/value/icon/accentColor/atual/anterior/isHistorico/isInverso/subValue; accentVar só aceita --brand-action / --brand-contrast / --brand-icon-color. Estado Carregando usa SkeletonKpiCard (não zera KPIs em 0 durante o load).
  • Nomenclatura Renomeei a "Strip Atenção" da v1 para Pontos de Atenção — mesmo nome já usado no bloco equivalente de Overview Prestador, para manter linguagem de produto consistente.
  • Fora de escopo v1 (mantido) Drill-down por mesa/dealer, exportação, alertas automáticos, custo financeiro. Comparativo por Estúdio agora é uma sugestão a decidir, não mais um "não" fechado.
