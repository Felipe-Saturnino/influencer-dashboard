Regras de permissão (proposta)

  • Atestados Colunas: Data da Solicitação · Solicitante · Descrição · Status · Ações. Ver = Próprios → só linhas das suas gerências. Modais Ver (abas Dados / Histórico) e Atender = os mesmos da página atual (ModalsVerAtender), com Histórico novo no Ver. Atender só com Editar = Sim.
  • Reuniões Colunas: Data Solicitada · Solicitante · Time · Tipo · Status · Ações. CTA Agendar Reunião → modal com Tipo, Prestador (escopo Próprios/Sim), Data Solicitada (só dias escalados futuros), Observação. Ao agendar: linha com Status Em análise; prestador = Solicitante. Ver → Solicitação de Reunião + subtítulo [tipo]; abas Dados / Histórico. Atender → abas Dados / Atendimento; Status Aprovado|Rejeitado; se rejeitado: Data de Reagendamento + Observação.
  • Vagas Colunas: Data da Solicitação · Solicitante · Time · Tipo de Vaga · Status · Ações. CTA Solicitar Vaga → Organograma (escopo Próprios/Sim), Data de Entrada (≥15 dias úteis), Turno, Tipo (Substituição + Prestador/Obs ou Nova entrada + Briefing). Ao solicitar: Status Em análise; usuário = Solicitante; Organograma = Time. Ver / Atender — Ver com abas Dados / Histórico; Atender só com Editar = Sim — Atendimento: Status Aprovado|Rejeitado + Observação.
  • Feedback Colunas: Data do Registro · Liderança · Prestador · Recomendação · Status · Ações. CTA Registrar Feedback → Time (escopo Próprios/Sim), Prestador do time, Recomendação, Observação. Ao registrar: Status Em análise; usuário = Liderança; Data do Registro = agora. Ver → abas Dados / Histórico; subtítulo [Recomendação] - [Status]. Atender (Editar = Sim) → Dados / Atendimento; se Aprovado + notificação contratual: anexo Evidência.

Modal Ver — abas (todas as filas)

  • Dados — campos atuais do Ver de cada aba.
  • Histórico — criação (usuário + data/hora); em Atendimento: usuário + data/hora + alteração de status + todos os campos preenchidos no Atendimento (ex.: Atestado aprovado → Observação do RH + Abono remunerado?; Reunião rejeitada → Observação + Data de Reagendamento; Feedback com notificação → Observação + Evidência).

Comportamento — Todos Status

  • Clicar (inativo) → ativa Todos Status (carrossel mostra «Todos Status»).
  • Clicar de novo (ativo) → desativa e volta ao status Em análise.
  • Setas do carrossel continuam Em análise ↔ Aprovado ↔ Rejeitado; ao sair de «Todos Status» via seta, o pill desativa.

Ordenação

  • Todas as abas usam cabeçalhos clicáveis no padrão SortTableTh (ícone ▴▾).
  • Coluna de data inicia em desc (mais novo → mais antigo). Clique alterna a direção; outra coluna torna-se a ativa.
  • Coluna Ações não é ordenável.

O que sai da UI atual

  • Select Todas Solicitações (Atestado / Vagas / Reunião com RH) — substituído pelas abas.
