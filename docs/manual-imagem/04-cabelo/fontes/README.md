# Fontes — Tema 04 Cabelo

| Fonte | Uso nesta política |
|---------|---------------------|
| *Guia Pocket* (regras comuns + feminino pp. 3–4 + masculino pp. 6–8) | Cor natural; não cobrir os olhos; raiz até 2 cm; franja; um coque/rabo; tranças sem contas; lace/peruca naturais; grampos/elásticos discretos; masculino: cabelo longo preso; harmonia cabelo/barba. |
| *IMAGEM DOS DEALERS E SHUFFLERS* (DOCX) | Franja curta não permitida; coloração com transições suaves; contraste topo/lados; peruca/toupee (linha capilar, densidade, fixação); acessórios grandes proibidos. |

Barba, bigode e sobrancelhas **não** entram neste documento — tema 05. Acessórios oficiais do uniforme: Política de Figurino.

Termo legado nas fontes (“Dealers”) → na política: **Game Presenter**.
